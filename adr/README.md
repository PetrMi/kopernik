# Architecture Decision Records

This directory contains significant architectural and product-engineering decisions for Kopernik.

## Status

An ADR should use one of these states:

- Proposed
- Accepted
- Superseded
- Rejected

Kopernik may create or recommend a Proposed ADR when a significant decision is required.

Only a human may accept, reject or supersede an ADR.

## Suggested structure

Each ADR should contain:

- Title
- Status
- Context
- Decision
- Consequences
