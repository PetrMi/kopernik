# UX Principles

## Understandable output

Reports SHOULD be understandable to an astrophotographer without requiring knowledge of the internal implementation.

## Measurements and interpretation

Reports MUST clearly distinguish measured values from assessments and diagnostic hypotheses.

## Explain assessments

When Kopernik provides an assessment, it SHOULD expose the measurements or rules that led to that assessment.

## Avoid false certainty

Uncertain conclusions MUST NOT be presented as established facts.

## Actionable errors

Errors SHOULD explain what failed and, when practical, what the user can do to correct the problem.

## Progressive complexity

Basic measurements SHOULD remain accessible without requiring users to understand advanced analysis features.
