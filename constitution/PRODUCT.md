# Product Principles

## Purpose

Kopernik provides objective information about the technical quality of astronomical FITS images.

Its purpose is to help an astrophotographer understand whether an image is suitable for further processing and identify possible quality degradation.

## Principles

### Evidence before interpretation

Measurements are preferred over subjective statements.

### Explain results

An assessment SHOULD explain which measurements caused it.

### Do not invent meaning

A measured value MUST NOT automatically be assigned scientific or quality meaning unless such interpretation is defined by the Constitution.

### Progressive analysis

Individual measurements SHOULD remain useful independently.

Adding a new metric MUST NOT require redefining unrelated existing measurements.

### Reproducibility

Given the same image, configuration and application version, analysis SHOULD produce reproducible results.
