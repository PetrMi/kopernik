# Scientific Principles

This document contains scientific and measurement assumptions used by Kopernik.

## Star detection

Star detection identifies image structures classified by an algorithm as stars according to defined detection parameters.

The number of detected stars is therefore a measurement produced by a specific method, not an absolute number of stars physically present in the field.

Star count may be affected by:

- detection parameters,
- focus,
- atmospheric transparency,
- clouds,
- background level,
- exposure,
- tracking,
- optical characteristics.

Therefore star count MUST NOT by itself be interpreted as an overall image-quality score.
